# Mini-Curso de Bun de A a Z

Curso prático de Bun em português europeu que mostra **o máximo possível das funcionalidades nativas, sem bibliotecas npm**: ficheiros, servidor HTTP com documentação OpenAPI e Swagger UI, cliente e Web APIs, SQLite, PostgreSQL e MySQL, Redis e S3, segurança, testes, bundler e executáveis, gestor de pacotes e concorrência. Todos os exemplos foram executados com o **Bun 1.4.0 no Windows 11**; a documentação oficial já descreve a 1.4.5, e as diferenças estão assinaladas nas aulas. Fio condutor: a API da «loja», os mesmos dados dos cursos de SQL, MongoDB e COBOL. Cada módulo tem a aula em Markdown, o documento Word completo e um PowerPoint com os pontos principais.

## Como estudar

1. Precisas do Bun instalado (o módulo 00 explica). Os módulos 05 e 06 usam Docker para o PostgreSQL, o MySQL, o Redis e o servidor S3; os restantes não.
2. Segue a ordem dos módulos 00 a 11, executando os exemplos das pastas `exemplos/`. Os dados da loja estão em `00-Introducao/dados/loja.sql`.
3. Resolve os exercícios do módulo 13 sem consultar o gabarito (cada aula indica quais).
4. Faz o projeto final (módulo 12) e usa o módulo 14 como consulta rápida.

## Limites e verificação

- O curso usa o Bun 1.4.0: opções que a documentação mais recente descreve podem não existir na tua versão. Confirma por execução.
- Quase tudo foi testado só no Windows 11: o comportamento em Linux e macOS vem da documentação.
- A renderização do Swagger UI no browser não foi testada (só o HTML e o JSON devolvidos).
- Os tempos medidos variam com a máquina; algumas peculiaridades podem ser defeitos da 1.4.0, entretanto corrigidos.
