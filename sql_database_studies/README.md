# Mini-Curso de SQL e Bases de Dados de A a Z

Curso prático de SQL em português europeu, do primeiro SELECT às consultas avançadas, com **foco nas diferenças entre dialetos**. Todos os exemplos foram executados em SQLite 3.45.3, PostgreSQL 17.12, MySQL 8.4.13 e SQL Server 2025 (RTM-CU6); Oracle e SAP HANA aparecem só em nota, marcada como não executada. Fio condutor: a «loja» (categorias, clientes, produtos, encomendas e linhas de encomenda). Cada módulo tem a aula em Markdown, o documento Word completo e um PowerPoint com os pontos principais.

## Blocos do curso

| Bloco | Módulos | Foco |
|---|---|---|
| Base | 01 a 03 | Consultas, agregação, funções, joins e subconsultas |
| Escrita e modelo | 04 e 05 | Modificar dados, transações, modelação e DDL |
| Avançado | 06 a 09 | CTE, janelas, índices, dialetos, SQL em código e objetos |
| Fecho | 10 a 13 | Projeto final, exercícios, consulta rápida e gabarito |

## Como estudar

1. Segue a ordem dos módulos 00 a 09, executando os exemplos. O ficheiro de dados está em `00-Introducao/dados/loja.sql`.
2. No início basta o SQLite (vem com o Python). Para comparar dialetos, usa PostgreSQL, MySQL e SQL Server em Docker (as aulas indicam os comandos).
3. Resolve os exercícios do módulo 11 sem consultar o gabarito (cada aula indica quais).
4. Faz o projeto final (módulo 10) e usa o módulo 12 como consulta rápida.

## Limites e verificação

- As diferenças entre dialetos foram **executadas**, mas os sistemas evoluem: confirma na documentação da tua versão.
- Oracle e SAP HANA não foram executados (não havia instância) e a aula di-lo.
- Os tempos de desempenho foram medidos numa só máquina e variam.
