# Mini-Curso de Python de A a Z

Curso prático de Python em português europeu, da instalação aos testes, ao Python idiomático e à biblioteca padrão, com um projeto fio condutor (gestor de despesas pessoais). Cada módulo tem a aula em Markdown, o documento Word completo e um PowerPoint com os pontos principais. Os exemplos foram executados com Python 3.13; o que não foi executado está assinalado nas aulas.

## Como estudar

1. Percorre os módulos 00 a 10 por ordem, escrevendo os exemplos num ficheiro `.py`.
2. Resolve os exercícios do módulo 11 sem consultar o gabarito (cada aula indica quais).
3. Usa o módulo 12 como referência e o módulo 13 para rever as soluções.
4. O módulo 14 mostra o Python em quatro áreas, com projetos prontos a executar em `14-Projetos-por-Area/projetos/`.

## Regenerar os ficheiros Office

    pip install python-docx python-pptx
    python tools/build_course_artifacts.py
    python tools/build_course_artifacts.py --only 04,05

## Convenções

- **DICA** sugere uma forma prática de trabalhar.
- **ATENÇÃO** assinala riscos para os dados ou para a segurança.
- **NOTA** acrescenta contexto.
- **PRATICAR** remete para um exercício do módulo 11.
